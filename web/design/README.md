# Bark landing page

## Design sources

`references/` contains the original supplied UI designs and definitive Byte character sheet. The duplicate world-code reference is stored once. `landing-concept.png` is the generated visual concept, not a production screenshot.

`landing-preview.png` shows the implemented homepage in Chrome. Lint and production build passed; browser checks covered desktop, tablet, mobile, customization, Play/Replay/Reset, dialog dismissal and focus restoration, tabs, expanding cards, and mobile section navigation.

The homepage uses navy rounded type, a pale blue/white canvas, blue primary actions, green play actions, purple code blocks, soft borders, and generous whitespace. Byte keeps his orange coat, cream markings, blue collar, and cursor-shaped tag. Reference 3D objects remain conceptual placeholders.

## Production assets

- `../public/images/landing/hero-world.png`: generated Byte and floating-island illustration.
- `../public/images/landing/byte-wave.png`: generated transparent mascot pose.

Generated from the supplied character sheet with the built-in image-generation tool. Originals remain in the generation output directory; production copies live in this repository. All copy and controls are real HTML, not flattened mockup text. The final implementation intentionally omits unsupported safety, social, and publishing claims present in the concept image.

## Implementation

`/` is the marketing homepage. `/components` remains the component showcase. The homepage reuses the shared controls and Motion configuration, including the explicitly requested full-motion policy.

The creation dialog is a local demo: name, setting, size, and sparkles persist while the page is mounted. Play animates Byte, completion changes the action to Replay, and Reset restores defaults. Closing cancels a running animation; reopening preserves customization. It does not call a backend, publish, or save a project. Illustrative code blocks and idea cards are previews, not an integrated editor.

Motion includes staggered entrances, drawn headline underlines, scroll-linked hero movement, pointer tilt, floating cards, blocks snapping into place, tab transitions, expanding idea cards, spring popovers, and demo movement. Repeating decorative animations stop when their scene leaves the viewport.
