# Rounded project models

These are original procedural meshes generated by `web/scripts/prepare-toy-models.mjs`. They use embedded geometry and solid PBR materials, with no external textures or model dependencies. The generator writes normalized, centered GLBs and their bounds manifest. Run `node web/scripts/prepare-toy-models.mjs`, then `node web/scripts/render-catalog.mjs` with the web development server running to regenerate matching engine-rendered thumbnails.
